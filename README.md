# Alder Creek Farm

## Explore the farm in your browser

**[Download the standalone HTML viewer (36 MiB)](https://github.com/Crinklyink/models/releases/download/alder-creek-daylight-v1/Alder-Creek-Viewer.html)**. Open the downloaded file in a modern browser, then select **Explore in 3D**. It includes the lighter farm model, the renderer and its sky. No server, installation or internet connection is required after download.

Drag to orbit, scroll or pinch to zoom, and select **Farm lane**, **Yard**, **Tractor** or **Aerial** for the four viewpoints. To inspect the original model instead, select **Open full GLB** and choose the downloaded file below.

## Original full-detail model
